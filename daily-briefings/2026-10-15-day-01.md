## 2. Core Technical Lessons

- Network reachability is different from authentication.
- Authentication is different from authorization.
- An exposed interface does not prove the initial access method.
- Root cause, contributing factors, and impact must be analyzed separately.
- A successful HTTP status code alone does not prove an authorization vulnerability.
- Heartbleed demonstrated how incorrect length validation can expose process memory.

## 4. Main Conclusion

A plausible attack path is not a proven attack path. Establish what is known, test hypotheses safely, document evidence, and make recommendations that address the demonstrated risks.
